Settings

Used only to obtain an anonymous auth token, the same way Morfix's own frontend does. Not a secret — this key just identifies the Firebase project. Pealim needs no key at all — it's a plain page fetch.
When this device is on your tailnet, lookups go through your Pi, with no public CORS proxy involved. Off the tailnet the relay doesn't answer and the proxies are used instead. Leave this blank to always use the proxies. Stored only in this browser. While the relay is reachable, searches are also saved to a cache on the Pi that all your devices share, and a search this device hasn't cached is looked up there before going to the dictionary sites. It has the same 3-month lifetime. "Send this device's cache to the Pi" uploads what's already cached here (the newest copy of each item wins).
Checking cache…
Every Morfix/Pealim/Milog search result — and every Pealim conjugation table you expand with "View full conjugation"/"View all forms" — is stored here (with its source and the date it was retrieved), so repeating the same lookup reuses it instead of hitting the network. A cached result older than 3 months is treated as stale and automatically replaced by a fresh live lookup. Each dictionary column shows a "Refresh" link when it's displaying a cached result, to force a new lookup early. If a search fails (e.g. you're offline) and that exact word hasn't been cached, but it showed up as one of the matches in some other cached search, that entry is shown on its own labeled "partial match" rather than nothing. Use "Export as JSON" to save a copy of this cache and "Import JSON" to load one back in (importing merges into whatever's already cached here). If the Pi relay is set up, results are also shared through a cache on the Pi (see above).
Lookups try your Pi relay first when it's set up and reachable. Otherwise (or if it fails) they search through a chain of public CORS routes: corsproxy.io first, then a direct request, then allorigins and codetabs as fallbacks. Morfix additionally requires its bearer token to be forwarded, which only the Pi relay, corsproxy.io and the direct attempt can carry — so off the tailnet, if corsproxy.io ever goes down or gets rate-limited, Morfix searches may fail even while Pealim's still work fine.
